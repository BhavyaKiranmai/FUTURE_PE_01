# Future Interns - Prompt Engineering Task 1

## Project Title

AI Website Copy Generator for Local Businesses

## Business Chosen

Beauty Glow Salon, Vijayawada

## Objective

To create a reusable AI prompt framework that generates website-ready content for local businesses.

## Tool Used

ChatGPT

## Deliverables

* Homepage Copy
* Services Page Content
* CTA Sections
* Tone Adaptation Example

## Prompt Logic

The prompt framework collects:

* Business Name
* Business Type
* Location
* Target Audience
* Tone

Using these inputs, AI generates customized website content tailored to the selected business.

## Outcome

A reusable prompt system capable of generating website copy for multiple local businesses.
